# SEC07 / SEC08 / PRE01：会话与预设决策

2026-10-20。API 行为核验基线为 `354a3055b3e97b19f68c11c899b3d94233e962a0`；客户端固定官方 1.5.0 `fada664df7a294d1d1a9ca3e7cd3637069122f17`。
本文区分已确认规则、源码现状和待确认事项，不批准新模型或代表部署验收。

## SEC07 第一节：已确认的本地期限

用户已确认：有签名密钥的本地 JWT 会话，以 `app.token-expire` 为固定绝对期限；零配置默认 168 小时。活动请求和 `autoLogin` 不延长期限，到期重新登录，本批不加 refresh token 或期限字段。

现行实例 issuer 已把同一截止时间写入 JWT exp 和 `user_tokens.expired_at`；每请求取二者较早者，并要求当前数据库会话存在、用户启用。续期不能越过原 JWT exp。当前新密码/OIDC 会话期限均不读取旧 `jwt.expire-duration`，不要通过修改后者来调整新会话期限。

更改 TTL 不会重写已签 JWT；旧会话仍受原 exp 与数据库截止时间限制。轮换签名密钥可使旧签名失效，但本批没有执行轮换或撤销。

## SEC07 后续节：现状与未决事项

| 情形 | 当前行为 | 尚需决定或验证 |
| --- | --- | --- |
| 签名密钥为空 | 新凭据为随机 opaque token，DB 剩余期限小于 TTL/3 时滑动续期，没有绝对上限 | 用户最新决定本批暂停 opaque 变更，另行设计上线清理；当前行为保留 |
| 本地退出 | 同事务撤销当前会话并沿原有语义解绑该 UUID/用户的首条设备；其他会话保留 | 真实客户端退出及重新认证验收 |
| 管理员撤销 | 删除指定本地会话，缺行幂等；不解绑设备 | 真实管理操作验收 |
| 本地用户禁用 | 最新确认并由用户管理切片实现：同事务撤销该用户全部本地会话；重新启用需重登 | 管理UI及真实客户端的禁用/重登验收仍未完成 |
| 本地改密或重置 | 密码修改与该用户全部本地会话删除同事务，包括由 OIDC 登录签发的本地会话 | 真实管理/本人改密验收；不据服务层测试称客户端已验 |

这些动作不撤回已放行的在途请求，也不代表断开已建立的远程连接。

此前确认的目标：opaque 会话采用签发时 `app.token-expire` 固定绝对期限，
活动不延长，不增加 refresh 或新字段；上线时撤销全部旧 opaque 会话，
不采用保留历史滑动截止的方案。

用户在第5节的最新决定是“先暂停 opaque 变更，另行设计上线清理”。因此，
上述目标保留为后续设计依据，本批不合入 opaque 停续期或离线清理 CLI 草稿，
不实施所提议的会话 ID 上界清理方案。上线清理方式重新设计后再确定实施。
当前 opaque 滑动续期仍存在，线上会话没有被清理；已交付的 JWT 期限、
禁用/改密撤销及历史停用账号重启用时的撤销规则继续有效。

用户管理统一按至少保留一个启用管理员检查删除、禁用和降权，禁用管理员不计数；
有其他启用管理员时允许自操作。实现及自动化边界见[用户管理安全](user-management-security.md)。

## 现有 IdP 的退出边界

依据获授权的 OIDC 对话在 2026-10-20 对现有部署 `cf55cc21f9c604818cffda8faeab1230947ac67a` 的只读核对：

- Discovery 发布 `end_session_endpoint`，未声明或实现 Back-Channel Logout。
- OAuth revocation/introspection 端点存在，但当前 PUBLIC/none 客户端无调用权限；随机不存在 token 的无凭据探测均为 401，不能把 401 当作 token 已失效。
- 已实现的 RP 退出路径依赖用户浏览器的有效 IdP 会话或设备 Cookie 和合法 hint；当前 RustDesk 未登记退出回跳 URI。登录 callback 不能自动充当退出回跳。该有效退出路径撤销此用户在 IdP 的全部设备凭据与 OAuth 授权，并非仅当前 RP；也不代表其他 RP 的离线本地会话即时清除，不能把普通本地退出自动扩大为该动作。
- IdP 退出、禁用或改密撤销其自身授权，不会自动撤销本 API 自行签发的本地会话。IdP token 约 30 分钟的期限不是本地会话期限。

继续保持 PUBLIC/none、Code+S256、openid/profile。没有要求 IdP 增加私有能力，也没有新增远程 token/sid 存储、通知表或全局退出实现。本地退出不应冒称 IdP 全局退出。

此处是该次部署核对与既有测试的事实摘要，未在本批重新操作真实 IdP 会话。已有普通 OIDC 登录通过结论保留原范围。

## SEC08：用户最新决定，不建设本地验证

不建设本地 TOTP、邮箱验证、因素注册或挑战模型；原因素选型提案已撤回，不是待确认或待开发项。不要求现有 IdP 提供这些能力。

保留普通密码登录兼容。SEC08-A 已在密码/LDAP 查询及签发前，只允许 `account` 或历史省略的 type，且不得出现 `verificationCode`、`tfaCode`、`secret`。其他阶段或这些字段的任何出现（包括空串、null）返回 HTTP 400 error，不静默按普通密码签发。

固定 Flutter 与 Sciter 首次账号请求均省略上述三项，不受此边界影响。客户端可选二次验证分支仍保留契约描述，但本服务明确不支持，不把源码存在该分支当作建设认证能力的要求。

测试 `TestClientLocalLoginRejectsUnsupportedStages` 覆盖 26 个拒绝组合，使用有效密码验证原始用户/会话/日志/设备零副写，另有 2 个普通登录分支签发后实际令牌回读。本地全仓 race/vet/build 和独立审查通过；这是 HTTP/SQLite 证据，未新增真实客户端验收。
